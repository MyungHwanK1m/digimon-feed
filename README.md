# 👾 DIGI-FEED (디지몬 자동 서칭 & 모니터링 앱)

디지몬 관련 최신 뉴스, 피규어/굿즈 발매 정보, 디지카(카드게임), 커뮤니티 인기글을 **서버 비용 0원**으로 자동 수집하고 PC와 스마트폰(PWA)에서 한눈에 모아보는 실시간 모니터링 앱입니다.

---

## 🌟 주요 특징

1. **서버 비용 & 관리 부담 0원 (Serverless)**
   - 24시간 켜둘 서버가 필요 없이 **GitHub Actions**가 주기적으로 자동 수집.
   - 외부 유료/무료 DB 회원가입 없이 **GitHub 자체 저장소(Flat JSON)**로 관리.
2. **PC & 모바일 완벽 지원 (PWA)**
   - PC에서는 와이드 3열 그리드로 시원하게 탐색.
   - 스마트폰에서는 브라우저의 **"홈 화면에 추가"**를 누르면 앱스토어 설치 없이 실제 앱처럼 동작.
3. **취향 맞춤 필터 & 스크랩**
   - 카테고리 필터: `전체`, `🧸 피규어/굿즈`, `🃏 카드게임(TCG)`, `🎮 게임/애니`, `🔥 커뮤니티 인기글`
   - 실시간 키워드 검색
   - 즐겨찾기(스크랩) 기능 (브라우저 로컬 저장)
   - 다크 모드 / 라이트 모드 지원

## 🚀 빠른 시작 (로컬 실행)

### 1. 데이터 수집 실행
```bash
cd scraper
pip install -r requirements.txt
python crawl.py
```
실행이 완료되면 `public/digimon_feeds.json`에 최신 소식이 자동으로 수집/저장됩니다.

### 2. 웹앱 실행
```bash
# public 디렉토리에서 간단한 웹서버 구동
cd public
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`에 접속하면 완성된 앱을 바로 사용할 수 있습니다.

## ☁️ 무료 자동 배포 가이드 (클라우드 0원 운영)

이 프로젝트를 GitHub 저장소에 올리기만 하면 **자동 수집**과 **무료 웹 호스팅**이 완성됩니다.

### 방법 1. GitHub Pages로 무료 호스팅 (가장 추천)
1. GitHub에 새 저장소(Repository)를 만들고 이 폴더의 코드를 푸시합니다.
2. 저장소의 **Settings** -> **Pages** 메뉴로 이동합니다.
3. **Build and deployment** 항목의 Source를 `Deploy from a branch`로 선택하고, Branch를 `main`, 폴더를 `/public`으로 설정 후 Save를 누릅니다.
4. 이제 생성된 `https://<내아이디>.github.io/<저장소이름>` 주소로 접속하면 언제 어디서든 PC와 스마트폰에서 사용할 수 있습니다!

### 방법 2. Vercel 원클릭 배포
1. [Vercel](https://vercel.com)에 로그인 후 해당 GitHub 저장소를 Import합니다.
2. Root Directory를 `public`으로 설정하고 Deploy를 누르면 1분 만에 배포 완료!

## 📱 스마트폰에서 '앱'으로 사용하는 방법 (PWA)
- **아이폰 (Safari)**: 하단 공유 버튼(`공유 아이콘`) -> **'홈 화면에 추가'**
- **갤럭시/안드로이드 (Chrome)**: 우측 상단 메뉴(`⋮`) -> **'홈 화면에 추가'** 또는 앱 화면 하단의 '추가' 배너 클릭
- 홈 화면에 주황색 디지몬 아이콘이 생기며, 주소창 없는 깔끔한 전체화면 앱으로 쾌적하게 실행됩니다.
